# Contributing

Start in [GitHub Discussions](https://github.com/Healthcare-Agent-Protocol/healthcare-agent-protocol/discussions) with a question, workflow example, or proposal.

Join the [HAP-1 GitHub organization](https://github.com/Healthcare-Agent-Protocol).
Introduce yourself in Discussions and request an organization invitation.

Read the [contribution guide](community/contributing.mdx) for proposal and review guidance.

Use invented examples only. Never submit patient data, production records, credentials, or internal exports.
