# Contributing

Start in [GitHub Discussions](https://github.com/Healthcare-Agent-Protocol/healthcare-agent-protocol/discussions) with a question, workflow example, or proposal.

To join the [HAP-1 GitHub organization](https://github.com/Healthcare-Agent-Protocol), introduce yourself in Discussions and request an invitation.
You can participate in public discussions before joining.

Describe the business problem, proposed behavior, affected messages or schemas, failure cases, and compatibility.
Open a pull request when ready and link the discussion.
Use invented examples only. Never submit patient data, production records, credentials, customer scripts, or internal exports.
Do not claim vendor support or deployment without evidence and permission.

HAP-1 profiles, business contracts, schemas, and examples are pinned to `1.0-draft.1` during the current review.
Change the draft number only when maintainers explicitly decide to publish a new draft.

Contributions use the repository's [Apache License 2.0](LICENSE).
