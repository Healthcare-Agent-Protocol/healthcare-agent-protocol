HAP-1 is a working draft with no production release.

## Use invented examples

Use invented data in examples, tests, and GitHub conversations.
Never post patient or claim data, recordings, transcripts, credentials, tokens, or private keys.

For the protocol's access and privacy rules, see [identity and access](/spec/identity/hap-1).

## Report a security issue

Use [GitHub's private reporting form](https://github.com/Healthcare-Agent-Protocol/healthcare-agent-protocol/security/advisories/new).
Describe what is affected and how to reproduce the problem using invented data.
Keep exploitable details out of public discussions and issues.
